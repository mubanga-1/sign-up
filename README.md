# 📄 Sign-Up Form

## 📖 Overview

This project is a responsive sign-up form built as part of [The Odin Project's Foundations curriculum](https://www.theodinproject.com/lessons/foundations-sign-up-form). It focuses on creating a user-friendly form interface using HTML and CSS, emphasizing form validation and responsive design.

## 🛠️ Features

* **Responsive Design**: Ensures usability across various devices and screen sizes.
* **Form Validation**: Implements basic client-side validation for user inputs.
* **User-Friendly Interface**: Clean and intuitive layout for enhanced user experience.

## 🚀 Technologies Used

* **HTML5**: Structuring the form elements and layout.
* **CSS3**: Styling the form for visual appeal and responsiveness.

## 🎯 Getting Started

To view the sign-up form locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/mubanga-1/sign-up.git
   ```
2. Navigate to the project directory:

   ```bash
   cd sign-up
   ```
3. Open `index.html` in your preferred web browser.
